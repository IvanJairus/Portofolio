Why you should not trust this page

Anything can draw green ticks. Three things stop this one from being a drawing.

The answers are not written here

rules/fixture.json is produced by the Groovy classes in the repository. This page only has to match it, and the badge above says whether it did, in your browser, right now.

The source is pinned to a commit

Twenty-five repository files are vendored here verbatim and pinned by SHA-256 against one commit. CI refetches that commit and compares bytes, so a stale copy fails the build instead of quietly becoming a second implementation.

Absent evidence fails

Switch the run to refused and read the trace. The gate prints the rule it applied and the threshold behind it, then the stages after it go hollow rather than red, because they never ran.

Read the rules themselves

The repository holds the gateway, the five stage templates, the scripts they call, the Groovy classes, and a transcript of this chain running for real. That transcript is where the log format on this page comes from.
