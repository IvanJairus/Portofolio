Reference implementation · synthetic data

The run reports itself.

Three pipelines run on a weekly schedule, when nobody is on shift: the branch auto-sync, the domain-wide SAST scan, and the SonarQube sweep. Each one ends by sending an HTML report to the domain that owns the services. These are those reports: the same template, the same columns, the same wording a developer reads in their inbox. Names, hosts, project ids and links are removed, and the numbers are dummy data in the real shape. What is not dummy is the format, what each report chooses to put first, and the fact that the run writes it at all.
